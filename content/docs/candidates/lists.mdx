---
title: Organize candidate lists
description: Create a static shortlist, review AI proposals, and maintain membership without changing outreach approvals.
---

A list is a named set of candidates. Use it to preserve a shortlist or prepare a mission selection. A saved personal view preserves filters and columns; it is not a shared candidate list.

## Before you start

Have candidates available in **Candidates**. For an AI list, describe what makes a person relevant and what evidence the selection should use.

## Create a list

1. In **Candidates**, select **Create list** to open **List builder**.
2. Choose **Manual List** to build from selected candidates, or **Create with AI** to describe the cohort you need.
3. For a manual selection, inspect the selected people, enter **List name**, and select **Create List**. You can also open the manual builder through **Create List** in the table's selection bar.
4. For an AI proposal, describe the objective in the conversation. Select **Review full proposal**, inspect every proposed candidate and supporting fact, and save the finite set you want to retain.

In the candidate table, **Select all on page** selects the displayed page, not every candidate matching your filters. Recheck the selected count before creating a list.

## Maintain membership

Select candidates and use **Add to List** to add them to an existing list. In a list, use **Remove from current List** to remove selected members. A candidate's details also shows their **Lists**, with **Add to List** and **Remove** controls.

Changing list membership organizes your candidates; it does not approve messages or automatically update a mission's already confirmed cohort. Review mission membership separately.

## Archive a list

Use the list's archive action and review **Archive List**. The list becomes read-only and is removed from import and mission destinations, while historical references remain available. Archiving a list does not mean deleting its candidates.

## Check the result and recover

Open the saved list and verify its name, members, and count. If an AI proposal is too broad, refine the request before saving. If an archived list is missing from destination choices, choose an active list rather than retrying the same selection.
