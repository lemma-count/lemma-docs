---
title: Import candidates from LinkedIn
description: Import a native search or one profile and track what was actually saved.
---

Use the direct import form when you already have a LinkedIn search or profile URL. For an exploratory search that still needs refinement, begin with the [recruiting conversation](/candidates/search).

## Before you start

You need a healthy connected LinkedIn account with access to the search's product. Pausing outreach does not necessarily prevent search reads, but a disabled or unhealthy connection cannot run the import.

## Start the import

1. Open **Candidates** and select **Add candidates**. In **Import candidates**, choose **LinkedIn search**.
2. Paste the native search or individual profile URL into **LinkedIn URL**.
3. Choose the **LinkedIn account** and read any product mismatch notice.
4. For a search, set **Max profiles to fetch**. This caps the fetched profiles; duplicates, Do Not Contact restrictions, and unreadable rows may reduce the number saved.
5. Choose a destination list if you want one, or keep the candidates without a list. Review the optional enrichment choice.
6. Select **Start import** and follow the run under **Recent imports**.

A search continues through pages rather than being limited to its first sample. An individual profile URL imports that profile rather than running a people search.

## Check the result

Read the import's counts and status, then inspect the saved people in **Candidates** or the destination list. Classic search may initially supply only a headline; role and company can fill in later from headline parsing. Review the [profile evidence](/candidates/review-profile) before relying on inferred fields.

An import creates or updates candidate records. It does not authorize messages or enroll everyone in a mission.

## If the run pauses or fails

**Paused (rate-limited)** means the provider has limited the work. Follow the run's status hint rather than starting duplicate imports. For **Needs attention** or **Failed**, read the specific error and check product access and account health. **Cancel** stops an in-progress run; it does not undo candidates already saved.

Continue with [organize lists](/candidates/lists) or [search and import troubleshooting](/help/search-import).
