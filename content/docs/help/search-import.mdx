---
title: Diagnose a search or import
description: Find the current import outcome and recover the specific failed step.
---

Search results, saved candidates, and list membership are separate outcomes. A preview or requested maximum does not prove that all those people were imported.

## Before you begin

Identify the original search or import, its connected account, and the intended destination list. Keep the visible error and run details. For a LinkedIn search, verify access to the actual product used: Classic, Sales Navigator, or Recruiter.

## Inspect the run

1. Open **Updates** to review background imports. Open the relevant import details or its original import screen.
2. Read the status and recorded counts. A run can be pending, importing, rate-limited, awaiting attention, completed, failed, or canceled.
3. Compare created or added candidates with skipped records, updates, errors, and list-routing results where shown.
4. Read the error or recovery guidance for that run. Check the connected account if the refusal concerns access or readiness.

An import does not create approved outreach. A rate-limit pause is not permission to launch repeated copies of the same import.

## Recover a spreadsheet step

If staging was interrupted and **Retry upload** appears, use it to resume the upload. Check the worksheet and field mapping before continuing.

If candidates imported successfully but list routing failed, choose **Retry adding imported candidates to the list**. This repairs the destination step rather than requiring a new import of the entire spreadsheet.

## Stop or escalate

Use **Cancel** on an in-flight LinkedIn import when offered. Check the final recorded counts afterward; cancellation does not imply earlier imported candidates were removed.

If the run is unavailable or its outcome uncertain, do not infer failure from an empty screen. [Contact Support](/help/support) with the source, run, destination, and error.
