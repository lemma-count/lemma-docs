---
title: Understand statuses and evidence
description: Distinguish drafts, approval, waiting work, and confirmed external actions.
---

Read a status in its own context. Import progress, Mission state, sequence state, and send evidence describe different things.

## Before you begin

Open the affected record in the correct workspace. If the screen reports unavailable or stale data, refresh it before drawing conclusions.

## Read sequence states

In **Work → Sending plan**, open a sequence and inspect its next action and history.

| State or view | How to use it |
| --- | --- |
| **Needs you** | Open the item and review the action it requests. |
| **Ready** | Eligible work still depends on account execution checks. |
| **Scheduled** | Inspect the planned time and its timezone. |
| **Waiting** | Read the condition that must be satisfied first. |
| **In conversation** | Review the candidate’s reply and recorded conversation. |
| **Paused** | Identify the Mission, account, or channel hold. |
| **Problems** | Read the failure or blocker before retrying. |

**Completed**, **Stopped**, **Canceled**, and **Failed** are distinct closed states. A closed sequence is not necessarily a successful send or a completed hiring outcome.

## Establish what happened

Inspect **Execution diagnostics**, **Proof**, and **Durable history**. **Current canonical truth** differs from **Projection update pending**, **Partial evidence**, or **Ambiguous truth**. Use provider-confirmed evidence to establish a send; approval records establish authorization instead.

A relative follow-up can be waiting for a prior confirmed send. Do not treat that condition as a failure or assume it has an absolute appointment time.

## If the state is unclear

Refresh the current sequence and compare its evidence. If uncertainty remains, [contact Support](/help/support) with the exact item and displayed explanation before requesting another send.
