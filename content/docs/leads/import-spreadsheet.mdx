---
title: Import Leads from a spreadsheet
description: Choose a destination, map one sheet, review the rows, and merge them into the Lead library.
---

Use the spreadsheet flow when you already have a legitimate Lead file outside Lemma.

<Outcome title="Outcome">
Selected rows with a valid email or LinkedIn profile identity are created or merged. The final summary shows created, updated, skipped, and error counts.
</Outcome>

## File requirements

Lemma accepts CSV, TSV, XLSX, XLS, XLSB, and ODS files. Each selected sheet can contain up to 5,000 rows.

Use one row per person and clear column headings. Include a valid email or `linkedin.com/in/…` URL when possible. A company or Sales Navigator URL can be preserved as an attribute, but it does not identify a person.

## Import the file

<Steps>
<Step>

### Choose the destination first

Open [**Leads**](https://app.heylemma.com/leads), choose **Add leads**, then select **Upload CSV**.

If active Lists exist, choose **Add imported Leads to a List** before uploading. Choose **Leads only — no List** when you do not want List membership. If no List selector appears, create a List first or import to the global library.

</Step>
<Step>

### Upload the file

Drop one supported file into the upload area. If the workbook contains several sheets, choose the one to import.

</Step>
<Step>

### Review the mapping

Lemma proposes how each column maps to a canonical Lead field, an existing attribute, a new attribute, or **Skip**. Correct any proposal that does not match the source data.

</Step>
<Step>

### Review and edit rows

Spot-check the grid. Correct cells and untick rows you do not want to import. Changes remain local until you confirm the import.

</Step>
<Step>

### Check the merge preview

The confirmation step reports:

- rows matched by email;
- rows matched by LinkedIn profile;
- rows without a valid identity;
- invalid email or LinkedIn values;
- repeated identities within the file;
- matches to existing Leads.

This preview does not decide Do not contact, Mission eligibility, or outreach permission.

</Step>
<Step>

### Choose the merge strategy

Choose:

- **Preserve existing values** to fill blanks without replacing conflicting data; or
- **Overwrite existing values** to replace conflicting non-identity values.

Email and LinkedIn identity values are filled when missing; they are not replaced by this strategy.

</Step>
<Step>

### Confirm the import

Choose **Import Lead** or **Import Leads**. The result shows created, updated, skipped, and error counts.

If Lead creation succeeds but destination routing fails, choose **Retry adding imported Leads to the List**. Do not upload the file again merely to repair List membership.

</Step>
</Steps>

## Duplicate behavior

Repeated rows and existing matches merge into one canonical Lead. Reimporting the same file can still overwrite values when you choose the overwrite strategy and can create confusing operational work, so use the import result before retrying.
