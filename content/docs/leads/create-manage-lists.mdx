---
title: Create and manage Lists
description: Create a static Lead set, maintain its membership, and archive or restore it safely.
---

A Manual Mission requires one active static List containing 1–5,000 Leads.

## Create a Manual List

<Steps>
<Step>

### Select the Leads

Open [**Leads**](https://app.heylemma.com/leads). Select the rows you want, then choose **Create List** in the bulk action bar.

You can also choose **Create list** without selecting rows to create an empty List.

</Step>
<Step>

### Keep Manual List selected

The **List builder** opens on **Manual List**. Enter a descriptive List name. Names can contain up to 120 characters and must be unique in the workspace.

</Step>
<Step>

### Choose Create List

Selected Leads are added. A Lead can belong to several Lists.

</Step>
</Steps>

## Create with AI

Use **Create with AI** to describe a finite audience in plain language. Lemma proposes matching Leads and explains the proposal. Choose **Review full proposal**, inspect every Lead and fact, then create the static List only when the proposal is correct.

An AI proposal is not a live dynamic segment and does not prove that every proposed Lead is eligible for outreach.

## Add or remove members

- Select several Leads and choose **Add to List**.
- From a List, select Leads and choose **Remove from current List**.
- Open a Lead’s action menu for **Add to List** or **Remove from List**.
- Open the Lead drawer to manage its Lists one at a time.

A List can contain at most 5,000 Leads.

## Rename or duplicate

Open a List from the sidebar:

- **Rename** changes the name without changing membership.
- **Duplicate** creates an independent static copy of the current membership.

Changing the original after duplication does not update the copy.

## Archive or restore

Choose **Archive List** when the List should no longer appear as an import or Mission destination. The List becomes read-only and historical references remain.

Open **Archived Lists** at the bottom of the Leads sidebar and choose **Restore** to make it active again.

<HelpCallout type="warning" title="Mission membership does not stay live-linked">
A Manual Mission freezes the selected List membership atomically when you choose **Launch Mission**. Later List edits do not change that launched audience.
</HelpCallout>

## If the List does not appear in Manual Mission

Confirm that it:

- is an active static List;
- contains at least 1 and no more than 5,000 Leads;
- is not archived.

Then refresh [New Mission](https://app.heylemma.com/missions/new).
