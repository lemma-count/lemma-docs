---
title: Review and publish context changes
description: Compare suggested changes, correct them, and publish the version you want Speiros to use.
---

Speiros prepares suggestions for your recruiting context. Review their facts and wording before publishing them, especially details about compensation, location, employment terms, or the interview process.

## Before you start

You need a proposed change in **Recruiting context**. Use [company context](/recruiting/company-context) or [context sources](/recruiting/context-sources) to prepare one.

## Review a change

1. Open **Recruiting context** and select **Needs review**.
2. Under **Suggested changes**, open a proposal. For an existing section, inspect the comparison with the page as it stood when Speiros prepared the change.
3. Check the title, facts, source material, and any uncertainties. Edit the proposed title or text if needed.
4. Select **Accept and publish** when the content is ready, or **Reject** if it should not replace the current section.
5. Open the section and read the published result.

When several proposals are ready, **Accept and publish all** accepts the batch. Review every proposal first; older proposals that cannot be compared may need individual review.

## Check the result

An accepted change is published as part of the acceptance step. You should see the corrected section in the context navigation. A rejected proposal leaves the existing section in place.

## Recover an incomplete review or publication

If the page changed after a proposal was prepared, return to the current section and ask Speiros to prepare a fresh change. Do not approve an outdated comparison simply to clear the review queue.

If **Publication incomplete** appears, accepted changes have not reached the published context. Select **Retry publication**, then check the section again. You do not need to rewrite the same change just because publication failed.

If a section is wrong after publication, ask Speiros to correct that specific section and review the new proposal. Conversation history is available through **Show conversation history**; use it to recover the facts you supplied.
