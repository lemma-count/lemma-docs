---
title: Add and maintain context sources
description: Use the conversation to provide references and inspect what your recruiting context is based on.
---

A source is reference material. A context section is the reviewed account Speiros prepares from that material. Supplying a reference and accepting its proposed changes are separate steps.

## Before you start

Open **Recruiting context** in the correct workspace. Decide what the material should explain: company culture, a role, team responsibilities, or interview process. Use material you can verify and share for this purpose.

## Provide a reference

1. Select **Build context with Speiros** in an empty workspace, or **Open Speiros** when context already exists.
2. Paste the relevant facts or a website URL into the conversation. Explain its purpose and which sections it should update.
3. To use a file, attach it in the conversation and explain what to extract. Wait for Speiros to acknowledge whether it could read the material; an attached file alone does not prove its contents were incorporated.
4. If you want Speiros to use a connected tool, make it available through the conversation's tool selector. Follow [connect a tool](/settings/tools) for account and access setup. Ask for a specific document or resource rather than an unspecified account-wide import.
5. Answer follow-up questions and open **Needs review** for the proposed changes.

For example: “Use these interview notes to update our interview process. Keep the company overview unchanged. Our old three-stage process has been replaced by two interviews.”

## Inspect existing sources

Select **Sources** in the context navigation when it is available. It lists source titles and types. Open a context section to see its cited **Sources**, where present. This helps you check which material supports a claim.

Sources is a reference list, not a document editor. Ask for corrections through the conversation and review the resulting section changes. Do not assume a website or connected document is continuously synchronized.

## If a source cannot be read

Provide the relevant text directly or another accessible reference. A connected tool does not guarantee that every document or page can be imported. If Speiros reports missing access or an unavailable operation, resolve that specific issue before relying on the material. In particular, do not treat connecting Notion as proof that a selected-page import has occurred.

Continue with [review and publish context](/recruiting/review-context).
