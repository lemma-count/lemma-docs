The Sender profile describes the person communicating with candidates. Company and hiring context belongs in [Recruiting context](/recruiting/company-context).

## Before you start

Open the intended workspace. Have accurate personal details and a booking link if you want Speiros to share one. LinkedIn import requires a connected LinkedIn account; manual entry is also available.

## Review and validate

1. Open [Settings → Sender](https://app.speiros.com/settings/channels) and scroll to **Sender profile**.
2. Review the existing details, or use **Import from LinkedIn** when available.
3. Correct the fields and **About** text so they accurately describe the person represented.
4. If needed, enter the exact appointment page in **Booking link**.
5. Use **Save draft** to keep unfinished changes. When the information is ready, choose **Validate** and confirm the **Validated** badge.

## Check the result

The profile is saved and its validation state is visible. Check **Durable coordinates** below it: captured values retain their source and verification state across reconnects and edits. A stored coordinate is not automatically a verified sending account.

A validated booking link can be shared in candidate conversations. Sharing it does not confirm that an interview was booked. To manage a reusable copy, see [Candidate resources](/settings/candidate-resources); later profile changes do not silently update that saved resource.

## If import fails

Read the import error. The current form is preserved, so you can correct it manually and validate it. If the account itself needs repair, use [Sender recovery](/settings/recover-sender). For a save or validation error that persists, [contact Support](/help/support).
