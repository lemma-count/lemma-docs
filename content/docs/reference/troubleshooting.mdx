Read the current explanation before reconnecting, recreating, or retrying. Broad resets can hide the real cause.

## Sender

### A healthy connection is not Ready

Refresh [Settings → Sender](https://app.heylemma.com/settings/channels). A healthy Connect or Replace normally becomes Ready automatically after provider verification, while Reconnect preserves the existing execution status. If the state is **Dry run** and **Activate sending** is available, verify the identity and choose it.

### Sender is Paused

Confirm whether the pause was intentional. Choose **Resume sending** only after resolving the reason.

### Sender is Restricted

Read the reason shown under **Execution**. There is no separate state-detail screen.

### Sender readiness is Unavailable

Choose **Retry**. Lemma keeps controls read-only until it can verify the authoritative state.

### Replace is blocked

Planned or in-flight work still references the current Sender. Stop, complete, hold, or let that work settle; existing tasks cannot be moved to the new account.

### Capacity is lower than the configured target

Compare **Daily target**, **Effective limit**, **Confirmed**, **Reserved**, and **Remaining**. Automatic warm-up starts with the first provider-authorized outreach activity, not when the Sender connects. Paid, Sales Navigator, and Recruiter Senders ramp across 14 days; new, free, and unknown Senders ramp across 21 days. The schedule, provider conditions, confirmed activity, and reservations can lower current availability further. See [Sender readiness, schedule, and capacity](/sender/readiness-and-schedule#understand-the-automatic-capacity-warm-up).

## Lead import

### LinkedIn URL is rejected

Use a people-search, compatible Sales Navigator search, or `linkedin.com/in/…` profile URL. A company page or post is not supported.

### No LinkedIn account can be selected

Connect an eligible account under **Settings → Sender**. A search product and account license must match.

### LinkedIn import appears stuck

Read its **Recent imports** card. **Pending** and **Running** are in-flight. **Paused (rate-limited)** means that run stopped and will not resume automatically: wait for the cooldown, then start a new import. Use **Cancel** only when you intend to end a genuinely in-flight run.

### Spreadsheet import is partial

Use the final counts and merge preview. Check invalid identity values, unticked rows, repeated identities, existing Lead matches, and destination List routing. Use the dedicated List-routing retry instead of uploading again.

## Mission

### Lemma-led Mission is waiting for approval

For a Mission-level request, open the Lemma-led Mission, confirm **Review approval**, and find the current **Approve** or **Deny** action in the conversation. For prepared message bodies, open the eligible Lemma-authored Sequence under **Outbox → Open** and choose **Validate sequence**, or use **Batch validate**.

### Manual Mission has no List

Create an active static List with 1–5,000 Leads. See [Create and manage Lists](/leads/create-manage-lists).

### Manual review changed

Choose **Refresh review**. The List revision, eligibility, Sender, playbook, or copy changed after the last calculation.

### Manual launch result is unknown

Use **Retry same launch**. It reconciles the durable command rather than creating a duplicate launch.

### An invitation note is rejected

Keep the rendered note at 200 characters or fewer. Invitation notes are available only for paid, Sales Navigator, or Recruiter Senders; omit the note for free or unknown Senders.

## Outbox

### A problem does not appear in Needs you

Open **Outbox → Open → Problems**. Needs you is only the subset with an action Lemma can currently offer.

### Scheduled time passed

Outbox formats timestamps and groups dates in Europe/Paris, while its editable **Send date** field uses the browser’s local timezone. Confirm both that browser timezone and the Sender’s configured timezone, then check the active window, capacity, holds, current touch, and provider evidence.

### Retry task is missing

The current Sequence is not eligible for that Manual recovery action. Do not create a substitute retry. Return to the Mission or use [Support](/reference/support).

### A reply suggestion cannot be edited

The current suggestion is read-only. **Queue reply** queues it verbatim when that action is available.

## Recovery order

1. Capture the Mission, Lead, Sender, action, status, timestamp, and timezone.
2. Read the Sequence history and Audit proof grade.
3. Fix the smallest actual prerequisite or apply the smallest hold.
4. Retry only when provider outcome and duplicate risk are clear.
5. Verify the resulting state and history.

## Next action

Use [Contact Support](/reference/support) when the authoritative state remains unavailable or contradictory.
