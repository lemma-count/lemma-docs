---
title: Contact Support
description: Open the verified in-product support channel and include the context needed to investigate.
---

Choose **Support** in the Lemma sidebar. The life-buoy button opens the in-product support chat.

This is the verified support route in the current product. This Help Center does not publish an unverified email address, response-time promise, or emergency SLA.

## Include useful context

Send:

- workspace name;
- Mission, Lead, and Sender names;
- the route or screen where the problem appears;
- exact visible status and action label;
- timestamp and visible timezone;
- a screenshot;
- import run, task, receipt, or short Audit ID when available;
- what you expected and what happened instead.

## Never send secrets

Do not include:

- passwords;
- one-time codes;
- session cookies;
- API keys or provider tokens;
- full payment-card details;
- unrelated personal data from a spreadsheet.

## If sending may be unsafe

Before opening chat:

1. choose **Hold LinkedIn** for the affected Mission or **Pause** for the Sender;
2. choose **Hold all manual sending** if every Manual Mission must stop;
3. capture the current Outbox and Audit evidence;
4. avoid retrying an unresolved provider action.

See [Pause, hold, stop, or complete work](/missions/pause-hold-complete).

## If Support does not open

Refresh Lemma, confirm you are signed in to the intended workspace, and try the sidebar **Support** button again. Preserve the route, timestamp, and screenshot for the next successful contact.
