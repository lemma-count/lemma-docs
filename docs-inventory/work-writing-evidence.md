## Editorial decisions

- Preparing a draft Mission precedes confirmation of its selected cohort. Neither action approves outreach.
- Connecting a Sender is distinct from authorizing a channel/account for a Mission. Initial preparation's default LinkedIn account lookup is a prerequisite source, not a claim that the UI asks for manual account selection on every creation.
- Review approval and Auto approval are mode controls; approval and provider-confirmed sends remain distinct.
- Five different scopes are described explicitly: Stop current turn, pause Mission, hold LinkedIn, revoke channel, complete Mission. DNC is candidate-wide and separate.
- Current source editor labels supersede old documentation labels: Save new revision, Remove touch, Add touch, Approve Sequence, Batch approve. No old Save touch/Validate sequence recipe reused.
- Shared source documentation contains stale LinkedIn-only/mixed-transport assertions. The new articles do not resolve rollout uncertainty by assuming either transport availability or inactivity.
- Internal code identifiers and implementation mechanics remain in this ledger rather than customer procedures.
