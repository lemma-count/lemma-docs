# Help Center presentation decision

Updated: 2026-10-05

Retain the established search-first home, six task shortcuts, shallow collections, article breadcrumbs, contextual navigation, table of contents, and previous/next progression. The October rewrite changes the information architecture to match recruiting while preserving the form the user liked.

## Current collections

Start here; Prepare a recruitment; Find and select candidates; Supervise the work; Connect and configure; Resolve a problem.

## Article pattern

Explain the task and expected outcome, state prerequisites, give concrete steps with current control labels, describe the resulting state, provide recovery guidance, and link to the next task. Distinguish scheduled work from confirmed provider outcomes.

## Visual treatment

Use the approved Speiros mark from the application, current Paper/Ink/accent colors, and the existing Inter Tight and Sometype Mono typography. Keep restrained reading surfaces and the existing architectural home illustration. That illustration is not a product screenshot.

## Usability checks

Verify home and article layouts at 1440, 768, 390, and 320 pixels. Preserve skip navigation, semantic landmarks, visible focus, mobile collection navigation, wrapping labels, and accessible search dismissal. Keep old URLs usable through the single redirect map.
