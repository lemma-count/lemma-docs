## Critical current contracts

- **DNC Undo:** removes global DNC only, preserves channel opt-outs, canceled work and historical facts. It is distinct from the 10-second queued reply Undo documented in Work.
- **Audit controls:** Action / All actions, Mission ID, Lead ID, From, To, Apply filters, Clear, Retry, Load 50 more. Proof grades: Control committed and Provider confirmed.
- **Support controls:** Support launcher/menu, New or New conversation, Attach image, Send, Try again, Retry, Retry attachment, Retry context. Text submission, image upload and context capture are distinct success states.
- **Timezone contract:** Sender window/status → Sender schedule timezone; booking → separate booking timezone; reply bubbles → receiving Sender schedule timezone; execution diagnostics/history → Europe/Paris; Audit and Candidate activity absolute timestamps → UTC. This is intentionally more precise than either “all UTC” or “all local.”
- **Imports:** spreadsheet upload retry and list-routing retry address different stages. LinkedIn cancellation must not be described as erasing already imported candidates. Preview, retrieval maximum, saved rows and list membership are distinct.
